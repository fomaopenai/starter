Начало работы с Fingular

=============================

Добро пожаловать в Fingular! Это руководство поможет вам настроить ваш первый проект всего за несколько минут.

Предварительные требования

-------------

Перед началом работы убедитесь, что у вас установлено:

\*   Node.js версии 16 или выше

\*   Python 3.8 или новее

\*   Git на вашем компьютере

\*   Аккаунт на GitHub или GitLab

\*   Базовые навыки работы с командной строкой

Установка

------------

### Вариант 1: Использование npm

\`\`\`bash

npm install -g fingular-cli

fingular init my-project

cd my-project

\`\`\`

### Вариант 2: Использование pip

\`\`\`bash

pip install fingular

fingular create --name my-project

cd my-project

\`\`\`

Настройка проекта

------------

1. Создайте конфигурационный файл:

\`\`\`bash

fingular config init

\`\`\`

2. Отредактируйте файл `fingular.config.json`:

\`\`\`json

{

  "apiKey": "your-api-key-here",

  "environment": "development",

  "port": 3000

}

\`\`\`

3. Установите зависимости:

\`\`\`bash

npm install

\`\`\`

Первый запуск

------------

Запустите ваш проект командой:

\`\`\`bash

fingular start

\`\`\`

Откройте браузер и перейдите по адресу `http://localhost:3000`

Основные команды

------------

\*   `fingular start` - Запуск сервера разработки

\*   `fingular build` - Сборка проекта для продакшена

\*   `fingular deploy` - Развертывание проекта

\*   `fingular test` - Запуск тестов
